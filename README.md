# Книжник

Читалка электронных книг для Android 4.0 и выше.

## Возможности

- Форматы: **FB2**, **EPUB**, **MOBI**
- Тёмная и светлая темы
- Изменение размера шрифта (A− / A+)
- Поиск по книге с подсветкой результатов
- Оглавление
- Закладки (до 5 на книгу)
- Цитаты (до 5 на книгу, копирование и сохранение выделенного текста)
- Сноски и примечания — встроенные ссылки на примечания в книгах FB2: нажмите на сноску → откроется текст примечания → кнопка «Вернуться» возвращает на место чтения
- Запоминание места чтения (автоматически при закрытии книги/программы)
- Нумерация страниц
- Полноэкранный режим (пункт меню «Полный экран», выход — кнопка «Назад»)
- Пролистывание страниц кнопками громкости (вверх — вперёд, вниз — назад)
- Вертикальная прокрутка текста пальцем
- Ползунок для быстрого перемещения по главе
- Выравнивание текста по ширине (с переносами) или по левому краю
- Иллюстрации: картинки в FB2 и EPUB отображаются в тексте
- Прослушивание книг: системный синтез речи (TTS), кнопка-ухо в нижней панели, автопрокрутка текста при озвучивании
- Piper TTS / RHVoice — пункт меню для настройки офлайн-нейроголосовых движков
- Синхронизация между устройствами через Google Диск (позиция, закладки, цитаты)
- Заставка-свиток при запуске и иконка приложения в виде свитка

## Сборка

Требования: JDK 11+, Android SDK (platform 34, build-tools 34.0.0), Gradle 7.6+.

```
gradle assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка

Скачайте APK нужной версии со страницы Releases и установите на устройство
(разрешите установку из неизвестных источников).

## Структура

- `app/src/main/java/com/example/reader/` — исходный код
  - `Fb2Parser.java`, `EpubParser.java`, `MobiParser.java` — парсеры форматов
  - `ReaderActivity.java` — экран чтения (TTS, цитаты, закладки, сноски, иллюстрации)
  - `LibraryActivity.java` — список книг (сканирование, разрешения, синхронизация)
  - `SplashActivity.java`, `ScrollSplashView.java` — заставка
  - `SyncManager.java`, `SyncPrefs.java` — синхронизация через Google Диск
- `app/src/main/res/` — ресурсы (макеты, строки, иконки)
